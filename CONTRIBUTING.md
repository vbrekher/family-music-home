# Contribute to Family Music Home

Thank you for helping improve this unofficial GPLv3 Navidrome fork. Contributions may be code, translations, theme fixes, documentation or a reproducible issue. Read the [developer guide](docs/en/developer.md), [русское руководство](docs/ru/developer.md), [architecture](docs/en/architecture.md) and [code of conduct](CODE_OF_CONDUCT.md).

## Report a problem

Search the project's existing issues, then report the exact release, browser/OS and minimal reproduction. Use synthetic accounts and audio you may redistribute. Include expected/actual behavior and relevant redacted errors. Do not upload a database, full log, private URL, credentials, music collection or family screenshot. Security reports belong in the private process described in [SECURITY.md](SECURITY.md).

## Submit a change

Keep the change focused and explain the user-visible result. Preserve Navidrome and third-party license notices. Use the existing code and design system. Run the checks relevant to your change, including authorization and failure behavior; report exact results and untested limits. Build and test locally with Docker; no hosted CI is required. Do not add an Actions workflow or a cloud deployment dependency to validate a PR.

Contributions are distributed under GPLv3 for the project's GPL code. Include compatible licenses and corresponding-source provenance for new third-party assets. Do not add proprietary audio/artwork, undeclared network telemetry or default external credentials. Original recordings and procedural demo artwork generated by the supplied demo generator are CC0.
