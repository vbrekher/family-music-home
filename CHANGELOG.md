# Changelog

## 1.0.0 — 2026-11-01

Family Music Home is an unofficial GPLv3 fork based on Navidrome v0.64.2. This source preserves upstream library browsing, player/queue, playlists, favourites, ratings, metadata, transcoding, administration and OpenSubsonic support.

- Adds eleven family workflows: Home, Shelves, Time Capsule, Music Letters, Music Requests, Forgotten Albums, Quality Passport, Library Doctor, Version Collector, Kids Music World and Legacy Export.
- Supports read-only Bunny, S3-compatible, SFTP with host-key verification, HTTPS WebDAV and NAS protocol access, with explicit user library grants.
- Provides optional checksum-pinned Lyrics, Apple Music metadata and Cover Art Archive plugin integrations and retains all 27 themes.
- Adds a protected public first run, arbitrary administrator credentials, explicit member grants and complete music-access revocation.
- Provides optional macOS Keychain-backed add-only Family Sync and a bounded local Docker Doctor companion.
- Adds complete encrypted stopped-volume backup/restore covering SQLite, plugin packages/KV stores and private family media, alongside compatible online backup formats.
- Introduces shared family page/dialog controls, responsive layouts, original project branding and paired EN/RU user documentation.
- Updates vulnerable dependencies, isolates prototype-sensitive configuration merges, permits canonical protected-account playback without privileged profile access, and redacts signed streaming parameters from logs.

Acceptance remains separately recorded in release reports. This entry describes implementation; it does not claim a completed personal production rollout, physical-device test or public publication before those actually occur.
