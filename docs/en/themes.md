# Choose a theme

Themes change the appearance, not music access. Each person chooses their own theme.

1. Sign in with your own account and open **Personal settings** from the account menu.
2. Find **Theme**, choose a theme and save. **Auto** follows the system preference; explicit themes keep the selected appearance.
3. Reload the page and sign in again to check persistence. Change another account separately to confirm it does not replace your choice.
4. For a difficult display, start with **Nord** or a light theme, enlarge browser text and check the player and dialogs before choosing a decorative theme.

All 27 inherited themes remain in the source registry. Availability of a theme is distinct from a completed visual accessibility audit; see the [UI audit](../design/UI_AUDIT.md) for measured coverage. If a theme has poor contrast, report its exact name, screen, browser and a synthetic screenshot. Never attach a personal library screenshot without reviewing its contents.
