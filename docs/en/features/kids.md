# Kids Music World

[English](../../en/features/kids.md) · [Русский](../../ru/features/kids.md)

Give a deliberately created protected account a simpler player, explicit library access and parent-controlled sharing.

## Before you start

Sign in to your own instance. Music selections require an indexed library you are allowed to read. No music is downloaded or purchased by these family tools.

## Use it

1. As an administrator, open Child accounts → Create child account.
2. Enter a unique username, display name and password of at least 12 characters. Select Allowed libraries, optional Stories libraries, interface and touch size.
3. Review the explicit confirmation and save. Sign in separately as that account, play permitted music and test a favorite. Switch to full interface only when appropriate; the same history is retained.

## Check the result and change it

Reopen the page and confirm the saved state. For editable records, open your own record to edit it; use archive controls when available. If access changes, unavailable music is redacted rather than granting new access. If saving fails, keep your draft, reload the latest revision and retry. Empty libraries are valid: add or scan your music first.

## Permissions and privacy

No child account is created automatically. Library access and server route guards apply even when calling APIs directly. Sharing with other adults is off unless explicitly enabled by the parent.

## Limits and troubleshooting

A simplified interface is not a substitute for server permissions. Test real client compatibility separately. Pausing the account disables catalog access; switching interface does not remove protected policy.
