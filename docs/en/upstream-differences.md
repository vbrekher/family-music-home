# Upstream and fork features

Family Music Home is an unofficial GPLv3 fork of Navidrome, not an official Navidrome release.

| Area | Origin |
|---|---|
| Catalog, artists, albums, playlists, player, transcoding and OpenSubsonic | Inherited Navidrome implementation |
| Eleven family modules, protected child policies, first-run hardening and family interface | This fork |
| Bunny, S3-compatible, SFTP and HTTPS WebDAV source adapters | Fork integration; users supply their own storage |
| Lyrics, Apple Music metadata and Cover Art Archive | Optional third-party plugins with separate licenses |
| Family Sync and Doctor companion | Local companion integrations |

See the [detailed differences and pinned upstream revision](../../UPSTREAM_DIFFERENCES.md), [third-party notices](../../THIRD_PARTY_NOTICES.md) and [authors](../../AUTHORS.md). Existing Navidrome copyright notices remain intact. Storage, hosting and optional external services are provided by their respective operators.
