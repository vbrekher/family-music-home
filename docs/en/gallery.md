# Application gallery

These are genuine browser captures of a local synthetic installation. Music, covers, names and messages are fictional. The original demonstration music and artwork are reproducible with the [local demo guide](local-demo.md). No personal server or family data is shown. Browser viewport emulation is not a physical phone test. New family screens use English labels; inherited Navidrome screens also support Russian.
