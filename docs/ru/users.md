# Пользователи и доступ к музыке

Добавлять пользователей и выдавать доступ к библиотекам может администратор. Для каждого человека создайте отдельный аккаунт: избранное, история, темы и семейные записи принадлежат аккаунту.

1. Откройте боковое меню → **Users / Пользователи** → **Create / Создать**.
2. Укажите уникальный логин, отображаемое имя и надёжный уникальный пароль. Email необязателен. Оставьте роль администратора выключенной для обычного слушателя.
3. Отметьте только разрешённые библиотеки. В новой публичной установке они не выбираются автоматически. Сохраните.
4. Войдите под новым аккаунтом в приватном окне браузера. Проверьте, что разрешённые альбомы видны, остальные библиотеки недоступны.
5. Для изменения доступа отредактируйте пользователя и библиотеки. В публичном режиме можно снять доступ ко всем библиотекам, сохранив аккаунт. Политика существующей приватной установки может отличаться.

Администратор имеет доступ ко всем библиотекам и настройкам сервера. Для передачи полки роль администратора не нужна. Общая семейная запись не открывает доступ к упомянутой в ней музыке: после отзыва библиотеки альбом в записи может стать недоступен.

Для ребёнка используйте [защищённый детский аккаунт](features/kids.md). Перед удалением пользователя при необходимости выгрузите его историю и сделайте [резервную копию](backups.md). Удаление аккаунта не является временной приостановкой доступа.

Если библиотека пуста, проверьте права, подключение источника и сканирование. После изменения прав проверьте новый вход. Не помещайте пароли, setup-token и сессии в скриншоты и обращения.
