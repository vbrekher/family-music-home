# Галерея приложения

Это настоящие снимки локального приложения с вымышленными музыкой, обложками, именами и сообщениями. Оригинальные демонстрационные материалы воспроизводятся по [руководству локального демо](local-demo.md). Личный сервер и семейные данные не показаны. Эмуляция viewport не является проверкой физического телефона. Новые семейные экраны используют английские подписи; унаследованные экраны Navidrome также поддерживают русский язык.
