# Установка Docker

[English](../../en/deploy/docker.md) · [Русский](docker.md)

Для первой установки используйте [Quick Start](../quickstart.md). `compose.family.yml` собирает `Dockerfile.family`, подключает музыку только для чтения, сохраняет данные приложения в named volume и открывает порт лишь на localhost. Bunny необязателен. Первая сборка скачивает зависимости, следующие используют локальный кеш Docker.

## Чем вы управляете

- `FMH_MUSIC_DIR`: существующая папка музыки на хосте. Не храните оригинальное аудио в каталоге данных приложения.
- `/data`: аккаунты, SQLite, плейлисты/история, приватные вложения и состояние плагинов. Сохраняйте том при замене контейнера.
- `127.0.0.1:4533`: локальный веб-адрес по умолчанию. Пример ограничен 1 GiB RAM и двумя CPU.
- Первый запуск: собственные логин/пароль администратора и локальный токен настройки. При наличии аккаунтов регистрация не открывается повторно.

Для проверки на специально созданных записях вместо вашей музыки см. [Local Demo](../local-demo.md).

## Другие устройства и HTTPS

1. Завершите локальную настройку, проверьте администратора и участника с явно заданными правами библиотек.
2. Настройте HTTPS на уже используемой инфраструктуре: действительный сертификат и подходящая авторизация. Обычный localhost не является установкой в Интернете.
3. Измените только нужную привязку порта/прокси. Сохраните авторизацию, защиту токеном и read-only музыку. Не публикуйте серверные секреты в Compose или Git.
4. В отдельной браузерной сессии проверьте вход участника, разрешённое воспроизведение, перемотку, отказ для чужой библиотеки и выход. Настоящие телефоны и приложения требуют отдельной проверки; desktop viewport не доказывает совместимость устройства.

UID/GID контейнера должен читать музыку и писать в собственный том данных. При переопределении пользователя сначала подготовьте владельца тома. Не открывайте всем доступ к файлам хоста ради обхода ошибки прав.

## Обычные команды

```sh
docker compose -f compose.family.yml ps
docker compose -f compose.family.yml logs --tail=80 music
docker compose -f compose.family.yml stop music
docker compose -f compose.family.yml start music
```

Перед обновлением сделайте [полную зашифрованную копию и проверку восстановления](../backups.md). `docker compose down` удаляет контейнер/сеть; `down -v` также уничтожает данные named volume и не является обычной командой удаления приложения. Исходная read-only музыка хранится отдельно. См. [обновление и откат](../updating.md).

Приёмка форка выполняется для `linux/amd64`, локально в Docker Desktop на macOS. Наличие исходников не означает физического тестирования каждой платформы и клиента оригинального проекта.
