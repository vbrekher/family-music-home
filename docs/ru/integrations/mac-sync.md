# macOS Family Sync

[English](../../en/integrations/mac-sync.md) · [Русский](mac-sync.md)

Необязательный помощник нужен, если сервер читает музыку из вашей приватной Bunny Storage zone. Он следит за `~/Music/Navidrome` и отправляет стабильные новые файлы **только Mac → Bunny**. Удаления удалённой музыки и незаметной перезаписи конфликта имён нет. Локальной Docker-установке Bunny-агент не нужен: её read-only папка уже находится на вашем компьютере.

## Однократная установка

Нужны macOS, Python 3.10+, существующий Bunny Storage write credential и пароль вашего администратора Navidrome. Registry PAT не требуется: загрузчик не использует Docker registry.

1. Из папки исходников запустите установщик со своими HTTPS-сервером, zone и логином администратора:

   ```sh
   python3 macos/navidrome_family_sync.py install \
     --music-dir "$HOME/Music/Navidrome" \
     --server https://music.example.com --zone YOUR_ZONE --owner YOUR_ADMIN
   python3 macos/navidrome_family_sync.py setup-keychain
   python3 macos/navidrome_family_sync.py status
   ```

2. Замените все примеры. Существующие credentials вводите только в защищённых интерактивных запросах Keychain. Account API key Bunny не нужен. Секреты остаются в macOS Keychain, а не в plist, config, аргументах и логах.
3. Проверьте `installed: true`, `paused: false`, `interval_seconds: 300`. Per-user LaunchAgent запускается при входе в GUI-сессию. Если macOS запросит разрешение уведомлений, разрешите его.
4. Скопируйте альбом в папку. Файл должен оставаться неизменным между двумя проверками с интервалом не менее 300 секунд. Обычное обнаружение занимает примерно 5–10 минут при включённом Mac; большие загрузки дольше. После проверенных загрузок агент запрашивает авторизованный scan сервера.
5. Откройте альбом на сервере и воспроизведите его. Следующая проверка неизменных файлов пропускает повторное хеширование и удалённые GET/PUT. Удаление локальной копии не удаляет объект Bunny.

## Управление

```sh
python3 macos/navidrome_family_sync.py sync-now
python3 macos/navidrome_family_sync.py pause
python3 macos/navidrome_family_sync.py resume
python3 macos/navidrome_family_sync.py logs --lines 40
python3 macos/navidrome_family_sync.py uninstall
```

Manifest — локальная SQLite в Application Support пользователя. Uninstall удаляет LaunchAgent, сохраняя музыку, manifest и Keychain. Короткая задача со статусом «not running» и последним кодом 0 между проверками работает нормально.

При недоступном Интернете или Keychain выполняются ограниченные попытки и последующее повторение. Конфликт имён сохраняется без повторного скачивания удалённого файла на каждом опросе. Неудавшийся scan остаётся ожидающим. После сна/входа launchd объединяет пропущенные интервалы; выключенный Mac ничего не загружает. Переименование может создать второй удалённый путь, поэтому намеренная удалённая очистка — отдельное действие оператора, а не автоматическая синхронизация.

## Что проверено

На настоящем Mac проверены Keychain, плановые загрузки MP3/FLAC, SHA-256, Range, scan, неизменные опросы, отказ при конфликте, сохранение удалённых оригиналов после локального удаления, перезагрузка и продолжение после последующего сна. Наблюдение видимого баннера уведомления остаётся **NOT_RUN**: успешная команда не доказывает, что macOS показала баннер. Полный MACOS_ACCEPTANCE_PASS для этого ненаблюдённого аспекта не заявляется. На вашем Mac нужно отдельно проверить разрешения ОС.
