# Хранилище SFTP

[English](../../en/integrations/sftp.md) · [Русский](../../ru/integrations/sftp.md)

Используйте этот источник, когда музыка должна оставаться в существующем хранилище. Приложение индексирует метаданные и читает разрешённые файлы по запросу, не зеркалируя всю коллекцию на том базы. Настроить origin и добавить библиотеку может только администратор сервера.

## Подготовка соединения

Создайте SFTP-аккаунт только для чтения музыкальной папки. Получите SHA-256 отпечаток SSH host key от администратора по доверенному каналу. Не считайте ключ доверенным лишь потому, что его вернуло соединение.

JSON-секрет содержит username и password либо private_key. Ключ должен поддерживаться SSH-библиотекой сервера; защищайте и меняйте его обычными средствами управления секретами. Несовпадение host key блокирует соединение.

Создайте управляемый оператором sources.json по примеру. Замените все значения; placeholder отпечатка SFTP намеренно не является действительным ключом.

```json
{
  "sources": [
    {
      "id": "home-sftp",
      "type": "sftp",
      "endpoint": "sftp://sftp.example.com:22",
      "root": "music",
      "host_key_sha256": "SHA256:YOUR_VERIFIED_HOST_KEY_FINGERPRINT",
      "secret_env": "NAVIDROME_SOURCE_HOME_MUSIC",
      "read_only": true,
      "enabled": true
    }
  ]
}
```

Подключите файл только для чтения и задайте ND_EXTERNALSOURCESFILE равным его пути внутри контейнера. NAVIDROME_SOURCE_HOME_MUSIC передавайте через защищённые секреты платформы, а не через опубликованный Compose. Перезапустите приложение для загрузки разрешённых origins. Обычные пользователи не могут передавать произвольные endpoints и credentials.

## Добавление и проверка

1. Войдите администратором и откройте External Music Sources. Найдите разрешённый ID источника.
2. Нажмите Test connection. До сканирования исправьте ошибки credentials, сертификата, host key или сети.
3. Нажмите Add library, затем Scan. В Users явно выдайте участнику доступ к этой библиотеке.
4. Войдите под этим участником. Найдите альбом, воспроизведите запись и проверьте перемотку. Выберите формат, поддерживаемый браузером или транскодером.
5. Отключите источник и убедитесь, что каталог сохранился, хотя воспроизведение временно недоступно. После восстановления включите его и повторите test/scan.
6. Remove association используйте только для намеренного удаления индексированной библиотеки и её записей каталога. Подтверждение не разрешает удалять оригиналы. Отдельно уберите или отключите операторскую конфигурацию, если источник больше не должен подключаться.

## Сеть и ошибки

Локальные и приватные назначения запрещены, пока оператор явно не разрешит необходимые диапазоны сети. Не отключайте TLS, host key и проверки DNS/IP ради соединения. DNS проверяется при подключении; редиректы не выполняются; разрешаются только настроенные ID источников.

Сетевой сбой не считается успешным пустым сканированием: прежний каталог остаётся. Проверьте статус, credentials только для чтения и достижимость, затем восстановите соединение. Лимиты листинга, стоимость запросов и исходящего трафика провайдера сохраняются. Плеер может выполнять Range-запросы, а транскодирование — читать больше аудио. Физический NAS и сторонние устройства требуют отдельной реальной приёмки; протокольные fixtures не доказывают совместимость оборудования.
