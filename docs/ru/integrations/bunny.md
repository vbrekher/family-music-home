# Музыка в Bunny Storage

Bunny необязателен: для локальной установки достаточно своей папки. Интеграция нужна для чтения приватной Bunny Storage Zone без копирования всей коллекции в `/data`.

1. Сохраните приватность зоны и используйте её правильный региональный HTTPS-origin. `BUNNY_STORAGE_ZONE`, `BUNNY_STORAGE_ACCESS_KEY` и необязательный `BUNNY_STORAGE_ORIGIN` храните в защищённой среде/secret store сервера. Для воспроизведения используйте read credential; загрузчику Mac отдельно нужен доступ на запись. Не помещайте ключ в URI библиотеки или скриншот.
2. Как администратор откройте **Libraries / Библиотеки** → **Create / Создать**, укажите название и путь `bunny://YOUR_ZONE/music`, заменив зону и префикс своими. URI обязан совпадать с настроенной зоной и не может содержать логин, пароль, query или fragment.
3. Сохраните и просканируйте. Проверьте альбомы, MP3, FLAC и перемотку. Сервер проверяет доступ к потоку; общая семейная запись не раскрывает ключ зоны.
4. Разрешите библиотеку нужным [участникам](../users.md), затем проверьте их аккаунт. Для прослушивания не нужна роль администратора.
5. При временном сбое восстановите подключение и scan, сохранив каталог. Удаляйте только конфигурацию подключения/библиотеки при осознанном отказе от источника. Не удаляйте объекты ради восстановления связи.

Для загрузки с Mac предназначен [Family Sync](mac-sync.md). Сканирование и read-only адаптер сами не загружают и не удаляют музыку. [Зашифрованные копии](../backups.md) используют отдельную явную конфигурацию записи (`BUNNY_STORAGE_PASSWORD` и backup key); read key воспроизведения не является ключом шифрования.

Origin и роли ключей своей зоны уточняйте в [официальной документации Bunny](https://docs.bunny.net/). Воспроизведение зависит от сети и провайдера; протокольный локальный тест не заменяет проверку реального origin.
