# Решение проблем

| Проблема | Что проверить |
|---|---|
| Браузер не подключается | Запущен Docker Desktop; `docker compose -f compose.family.yml ps`; правильный localhost-порт; порт свободен. |
| Запуск запрещён / permission error | Том данных доступен контейнеру для записи. Для вручную заданного UID оператор должен подготовить права каталога/тома. Не открывайте запись всем. |
| Не создаётся первый аккаунт | Токен именно этого экземпляра, допустимый логин, пароль от 12 символов. Если аккаунт уже существует, используйте обычный вход. |
| Музыки нет | Папка существует, read-only mount указывает на неё, scan завершён, теги корректны и аккаунту разрешена библиотека. |
| Удалённая музыка недоступна | Test Connection, DNS/сеть, провайдер, секрет, TLS/SSH-проверка. Сохраняйте каталог до восстановления связи. |
| Нет воспроизведения | Нажмите Play вручную; проверьте кодек браузера, вывод и mute; попробуйте поддерживаемое транскодирование; изучите логи приватно. |
| Нет перемотки | Источник должен поддерживать Range или используемое транскодирование; проверьте другой формат. |
| Нет записи/вложения | Автор и получатель, архив/фильтры, права на музыку и полнота копии. Не выдавайте администраторские права ради обхода. |
| Плагин не возвращает результат | Разрешения, доступность провайдера, подходящие метаданные и логи. Отсутствие текста/обложки не доказывает ошибку библиотеки. |
| Mac не загружает | См. [диагностику Mac](integrations/mac-sync.md): агент включён, Keychain доступен, сеть работает, ожидается очередной 300-секундный опрос. |

В обращении укажите релиз, браузер, ОС и небольшой синтетический пример. Проверьте логи на токены, адреса, имена людей и файлов. Не прикладывайте `/data` и полную копию. Перед изменением БД и развёртывания сделайте backup.
