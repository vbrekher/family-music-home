# Начните со своей музыки

[English](../en/quickstart.md) · [Русский](quickstart.md)

Нужны работающий Docker Desktop и папка с музыкой, которой вы вправе пользоваться. Bunny, аккаунт реестра и облачные сервисы не требуются. Первая сборка исходников занимает несколько минут; скорость загрузки зависимостей зависит от соединения.

1. Скачайте исходники релиза или клонируйте `https://github.com/aitishnyk/family-music-home`. Откройте терминал в этой папке.
2. Укажите папку с музыкой и запустите сервер:

   ```sh
   export FMH_MUSIC_DIR="$HOME/Music/Navidrome"
   mkdir -p "$FMH_MUSIC_DIR"
   docker compose -f compose.family.yml up -d --build
   ```

3. Прочитайте одноразовый токен установки локально. Не отправляйте его в issue или чат:

   ```sh
   docker compose -f compose.family.yml exec music cat /data/setup-token
   ```

4. Откройте [локальную страницу установки](http://127.0.0.1:4533). Выберите логин администратора и уникальный пароль не короче 12 символов. Введите токен и создайте аккаунт. Предустановленных паролей нет.
5. Дождитесь индексирования папки. Откройте Albums, выберите альбом и нажмите Play. Если браузер не поддерживает кодек FLAC напрямую, может потребоваться транскодирование.
6. В Settings → Users создайте обычного участника и явно проверьте доступ к библиотекам. Для защищённых детских аккаунтов используйте Child accounts. Ненужный общий доступ оставляйте выключенным.
7. Выберите личную тему в настройках. Изучите [11 семейных модулей](features/index.md), затем [резервное копирование](backups.md).

Папка музыки подключена только для чтения. Удаление контейнера не удаляет оригинальную музыку. Named volume `family-data` содержит аккаунты, историю и приватные вложения: не выполняйте `down -v`, если не хотите намеренно удалить данные приложения и не имеете проверенной копии.

По умолчанию сервер доступен только на вашем компьютере. Для других устройств сначала настройте HTTPS и авторизацию по [Docker-руководству](deploy/docker.md). Не открывайте незавершённую установку в Интернет.

При ошибке проверьте `docker compose -f compose.family.yml logs --tail=80 music`. Не публикуйте сырые логи с личными сведениями. Существующая база с аккаунтами не открывает первоначальную регистрацию снова. После регистрации файл токена удаляется при следующем перезапуске; сохранённая копия не позволяет создать второго первого администратора.
