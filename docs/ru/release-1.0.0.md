# Family Music Home 1.0.0

Неофициальный бесплатный форк Navidrome под GNU GPLv3. Полный исходный код сервера, интерфейса, внешних подключений и инструментов включён в релиз. Исходные авторские права Navidrome и уведомления зависимостей сохранены.

В этой версии доступны все 11 семейных модулей, обычная библиотека и проигрыватель Navidrome, 27 тем, внешние библиотеки Bunny/S3/SFTP/HTTPS WebDAV и три необязательных плагина метаданных. Новый сервер не получает личные учётные данные разработчиков: первый администратор создаёт свой пароль с помощью случайного установочного токена. Доступ новых пользователей к библиотекам назначается явно.

## Что проверено

Сборка и тестирование выполнены непосредственно на Mac в локальном Docker Desktop для linux/amd64. Подтверждены 85 пакетов Go, полный прогон интерфейса и отдельные проверки исправлений, 191 HTTP-проверка семейных сценариев, запуск с пустой базой, MP3/FLAC, отзыв доступа и восстановление полной зашифрованной резервной копии с двумя аккаунтами. Точные итоговые числа и области проверки приведены в [отчёте приёмки](../release/ACCEPTANCE.md).

Повторный скан образа после исправлений не обнаружил уязвимостей Alpine и Python. Неиспользуемый пакет OpenPGP остаётся в модульном инвентаре; анализ Go не обнаружил его среди импортируемых пакетов. Runtime-аудит npm чистый; в инструментах разработки остаются 22 предупреждения умеренной тяжести. Подробности — [отчёт безопасности](../release/SECURITY_REVIEW.md).

## Ограничения приёмки

Физические телефоны, планшеты и NAS, нативный масштаб браузера 200% и видимый баннер уведомления macOS не проверены. Проверка размеров экрана в браузере не выдаётся за проверку физических устройств. Новые семейные экраны пока имеют английские подписи; унаследованный интерфейс Navidrome поддерживает русский, инструкции доступны на обоих языках.

Личный сервер Bunny сохранён без изменений. Обновление заблокировано отсутствием доступного официального способа получить свежую полную копию production-тома, включая пакеты и состояние плагинов. Успешное локальное восстановление не заменяет эту копию; production PASS не заявляется. [Подробный статус](../release/PRODUCTION_STATUS.md).
