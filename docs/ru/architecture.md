# API и архитектура

Go-приложение обслуживает React WebUI и авторизованный Native API под `/api`. OpenSubsonic расположен под `/rest`; клиентская совместимость унаследована от Navidrome. Авторизация использует сессии/токены сервера; не вставляйте их в ссылки документации.

| Слой | Исходники | Назначение |
|---|---|---|
| Сервер и первый запуск | `server/`, `integrations/selfhost/` | Маршруты, вход, единственный первый администратор, setup-token |
| Native API | `server/nativeapi/` | Пользователи, библиотеки и семейные ресурсы с проверкой прав |
| Семейная логика | `core/family/` | Полки, письма, капсулы, запросы, Doctor, издания, Kids, Legacy |
| Хранение состояния | `persistence/`, `db/migrations/` | SQLite и версионированные миграции |
| Источники | `core/storage/`, `adapters/`, `integrations/external_sources/` | Local/Bunny/S3/SFTP/WebDAV, метаданные и streaming |
| WebUI | `ui/src/` | Музыкальный интерфейс, семейные экраны, темы и плеер |
| Плагины | `plugins/`, `integrations/plugins/` | WASM host с ограниченными capabilities и фиксированные manifests |
| Mac | `macos/` | Keychain, add-only sync, ограниченный локальный Doctor |
| Копии | `integrations/bunny/` | Онлайн-копия SQLite и отдельная полная копия остановленного тома |

Семейные ресурсы используют существующих пользователей, права библиотек и защиту детей. Ссылка на альбом не разрешает поток. Получатели и принадлежность вложений проверяются сервером. Записи используют revision и явные action endpoints против незаметной перезаписи конкурентных изменений.

Настройка удалённого источника доступна администратору и ссылается на имя секретной переменной. Read-only-протоколы не копируют всю коллекцию локально. Временное отключение сохраняет идентичность каталога; автоматическое удаление оригиналов не поддерживается.

Один persistent SQLite-том обслуживает один процесс записи. KV-базы плагинов и семейные вложения — отдельные файлы: полная копия включает их. Восстанавливаемые кеши исключаются полным backup helper.

Это карта архитектуры, а не обещание стабильности внутренних API. Точные схемы запросов смотрите в маршрутах и тестах. Для клиентских интеграций используйте OpenSubsonic, где это подходит.
