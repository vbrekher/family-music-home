# Частые вопросы

**Это бесплатно?** Приложение — свободное ПО GPLv3, без Premium, рекламы и обязательной подписки. Свой необязательный хостинг и storage вы оплачиваете самостоятельно.

**Это официальный Navidrome?** Нет, это неофициальный форк. Обычная библиотека, плеер и OpenSubsonic унаследованы; см. [различия](../../UPSTREAM_DIFFERENCES.ru.md).

**Обязательно нужен Bunny?** Нет. Начните с локальной папки только для чтения и Docker. Удалённое хранилище необязательно.

**Где взять музыку?** Используйте записи, которыми вправе пользоваться. [Локальное демо](local-demo.md) создаёт оригинальные тестовые звуки и обложки. Коммерческая музыка не включена.

**Family Sync удаляет облачную музыку?** Нет. Это только добавление/обновление Mac → Bunny; удаление локального файла не удаляет объект Bunny. См. [ограничения](integrations/mac-sync.md).

**Legacy ZIP — резервная копия?** Нет, это экспорт личной истории. Для восстановления нужны [полная зашифрованная копия](backups.md), соответствующий образ и конфигурация.

**Можно использовать телефон или NAS?** Совместимые клиенты и удалённые протоколы реализованы. Физические устройства и браузерные/протокольные тесты учитываются отдельно. Общего онлайн-демосервера нет.

**Почему в обычном WebUI нет текста песни?** Плагин предоставляет серверную возможность lyrics. Отображение и синхронные строки зависят от клиента; установка плагина не добавляет отдельную панель WebUI.

**Можно изменять и распространять коммерчески?** GPLv3 разрешает это при соблюдении условий, включая соответствующие исходники. Сохраняйте уведомления и сторонние лицензии.
